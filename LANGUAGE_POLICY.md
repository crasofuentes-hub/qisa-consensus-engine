# Repository Language Policy

This repository is **English-only**.

Scope:
- README and all documentation (docs/, paper/)
- Source code comments and docstrings (src/)
- Tests and benchmark output descriptions (	ests/, ench/)
- Release notes and metadata files (RELEASE_NOTES_*, .zenodo.json, CITATION.cff)

Rationale:
- Enables consistent academic and industry citation.
- Improves global accessibility and reduces ambiguity in audits.

If you find non-English text, please convert it to English in the same change.
